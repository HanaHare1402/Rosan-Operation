# Rosan-Operation

Bảng điều hành vận hành Team Vương (Phil): tổng quan, team, nhân sự, sản phẩm, đơn hàng, KQKD, cảnh báo, cài đặt.

**Trang web:** https://hanahare1402.github.io/Rosan-Operation/

- Toàn bộ trang nằm trong `index.html` (HTML + CSS + JS, không cần build). Mở trực tiếp bằng trình duyệt hoặc bật GitHub Pages (Settings → Pages → Deploy from branch).
- Dữ liệu hiện là **dữ liệu mẫu**. Đối soát file J&T/FFM (.xlsx/.csv) ở màn KQKD chạy với file thật, đọc ngay trong trình duyệt.
- Cài đặt shop sàn và đơn vị FFM: khi mở ngoài claude.ai thì lưu trong `localStorage` của trình duyệt (chỉ máy đó thấy).
